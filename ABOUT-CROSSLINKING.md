# v2.14 — About / Researcher Profile + Cross-linking

This pass replaces the placeholder About page with a standalone h00die-gr3y researcher profile and connects the three main technical content types more tightly.

## About

The new About page uses the established Knowledge Base tone: personal and practical without deliberately playful wording. It explains the research focus, working method, responsible-disclosure approach and where each part of the site fits.

## Cross-linking

Cross-links are derived from existing content metadata; no duplicate relation data is introduced.

- Research pages now show Knowledge Base entries that reference that research item.
- Research pages now show Articles that reference that research item.
- Article pages now show Knowledge Base entries that reference that article.
- Knowledge Base pages now show up to three other published entries in the same category, preferring overlapping topics.

This keeps Research as the vulnerability-specific record while making methodology and long-form context easier to discover.
